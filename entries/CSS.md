# CSS

CSS is a language that can be used to add style to an [HTML](/wiki/HTML) page.

## CSS Syntax

CSS is made up of selectors and declaration blocks. A selector points to the HTML element you want to style, and the declaration block contains one or more declarations separated by semicolons.

### Example

```css
h1 {
    color: blue;
    font-size: 20px;
}
```

In this example, the `h1` selector targets all `<h1>` elements, setting their text color to blue and font size to 20 pixels.
